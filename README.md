# มหาวชิราลงกรณบาลีเถรวาทราชวิทยาลัย (วส. มจร)
## ระบบบริหารจัดการสถาบันศาสนทายาทและบาลีศากยบุตรอัจฉริยะ (Enterprise Buddhist College ERP)

ระบบบริหารจัดการแบบบูรณาการสำหรับ **มหาวชิราลงกรณบาลีเถรวาทราชวิทยาลัย** ต.รางพิกุล อ.กำแพงแสน จ.นครปฐม วิทยาลัยสงฆ์ในกำกับของมหาวิทยาลัยมหาจุฬาลงกรณราชวิทยาลัย (มจร) ผสานวิถีชีวิตพระวินัย การสาธยายคัมภีร์บาลีโบราณ (สัททนีติ, ปทรูปสิทธิ, มูลกัจจายนะ) และการบริหารงานวิทยาลัยสงฆ์มาตรฐานสากล

---

## 🏛️ โครงสร้างระบบ ๑๓ โมดูลหลัก (Core Modules)

| โมดูล | ฝ่ายงาน / ระบบ | คำอธิบายและหน้าที่หลัก |
| :--- | :--- | :--- |
| **MOD-01** | **วิถีชีวิตและสุขภาวะสามเณร** | กิจวัตร ๒๔ ชม. (ทำวัตร, บิณฑบาต, กัมมัฏฐาน), เวชระเบียน EHR Lite, แจ้งเตือนอาหารโรงครัว |
| **MOD-02** | **ภัตตาหาร & โยมอุปถัมภ์** | ปฏิทินจองเป็นเจ้าภาพภัตตาหารเพล, ระบบ e-Donation สรรพากร ๒ เท่า, ใบอนุโมทนาบัตรทองคำ A4 |
| **MOD-03** | **มุขปาฐะ & บาลีศึกษา** | ประเมินผลการท่องจำพระคัมภีร์ปากเปล่า, คลังไฟล์เสียงสวด, แดชบอร์ดติดตามความก้าวหน้ารายรูป |
| **MOD-04** | **สารบรรณ & อนุมัติมือถือ** | ระบบเสนอแฟ้มและเกษียณหนังสือด่วนที่สุด, ลายมือชื่ออิเล็กทรอนิกส์ (Digital Signature) |
| **MOD-05** | **ทะเบียนสงฆ์ & เชื่อม มจร** | ทะเบียนสองมิติ (ฉายา/สมณศักดิ์ & บัตร ปชช.), ตัวส่งออกข้อมูลเชื่อมโยง MCU REG มจร วังน้อย |
| **MOD-06** | **บริหารผู้ใช้ & สิทธิ์สงฆ์** | การจัดการบัญชีและบทบาทตามพระวินัย (RBAC: พระเถระ, พระอาจารย์, พระพี่เลี้ยง, โยมอุปถัมภ์) |
| **MOD-07** | **ห้องประชุมอัจฉริยะ** | ระบบจองห้องประชุมวิทยาลัยสงฆ์, ป้ายหน้าห้องดิจิทัล (Smart Signage), จัดเตรียมน้ำปานะ |
| **MOD-08** | **บริหารงานบุคคล (HR)** | บริหารอัตรากำลังบรรพชิตและคฤหัสถ์ ๔๒ อัตรา, บันทึกประวัติสมณศักดิ์และการเลื่อนขั้น |
| **MOD-09** | **การเงิน บัญชี และพัสดุ** | บริหาร ๓ กองทุนบริจาค, ระบบคลังสังฆภัณฑ์และพัสดุครุภัณฑ์วิทยาลัยสงฆ์ |
| **MOD-10** | **แผนงานและงบประมาณ** | แผนยุทธศาสตร์ ๕ ปี, ติดตามตัวชี้วัด KPI มหาวิทยาลัยมหาจุฬาลงกรณราชวิทยาลัย |
| **MOD-11** | **พระไตรปิฎก & หอสมุด** | คลังสืบค้นพระไตรปิฎกบาลี ๔๕ เล่ม, สัททนีติปกรณ์, ปทรูปสิทธิ และคัมภีร์บาลีโบราณ |
| **MOD-12** | **วิจัย & คุณภาพการศึกษา** | คลังงานวิจัยพุทธศาสตร์, ระบบประกันคุณภาพการศึกษาตามเกณฑ์ AUN-QA และ EdPEx |
| **MOD-13** | **บริการการศึกษา** | ตารางเรียนบาลีศากยบุตร ๔ ชั้นปี, โครงการอบรมธรรมะและบริการวิชาการแก่ชุมชน |

## 🎨 Design System: Sacred Royal Heritage
* **อัตลักษณ์พุทธศิลป์โมเดิร์น:**
  * **Royal Gold:** `#C5A059`, `#D4AF37`, `#996515` (ทองคำเปลวและตราประทับเกียรติยศ)
  * **Civara Saffron:** `#7A3803`, `#934B17` (สีกาสาวพัสตร์พระวินัย)
  * **Royal Midnight Navy:** `#0B192C` (สีกรมท่าน้ำเงินลึกแทนความสุขุมสง่างาม)
  * **Warm Ivory:** `#FAF8F5`, `#FFFDF9` (สีพื้นกระดาษข่อยนุ่มนวล สบายตา)
* **Typographical Hierarchy:**
  * **Headlines / Pali:** `Noto Serif Thai`, `Sarabun`
  * **Body / UI:** `Be Vietnam Pro`, `Bai Jamjuree`

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
* **Frontend & Backend:** [Next.js 15 (App Router)](https://nextjs.org/) + React 19 + TypeScript (Strict Mode)
* **Styling:** Tailwind CSS + Lucide Icons
* **Database & ORM:** [Prisma ORM](https://www.prisma.io/) (SQLite สำหรับ Local Dev / PostgreSQL สำหรับ Production)
* **Data Validation:** Zod

## 🚀 การติดตั้งและเริ่มใช้งาน (Getting Started)

### 1. ติดตั้ง Dependencies
```bash
npm install
```

### 2. ตั้งค่าและซิงค์ฐานข้อมูล Prisma
```bash
npx prisma generate
npx prisma db push
```

### 3. รันเซิร์ฟเวอร์สำหรับการพัฒนา (Development)
```bash
npm run dev
```
เปิดเบราว์เซอร์ไปที่: [http://localhost:3000](http://localhost:3000)

### 4. Build สำหรับ Production
```bash
npm run build
npm run start
```

## 📜 กฎบัตรความปลอดภัยและพระวินัย
1. **เวลาและกิจวัตรพระวินัย:** การขบฉันภัตตาหารเพลต้องเสร็จสิ้นก่อนเที่ยงวัน (12:00 น.)
2. **การคุ้มครองข้อมูลผู้เยาว์ (PDPA):** ข้อมูลสุขภาพ ประวัติส่วนตัว และภาพถ่ายของศากยบุตรสามเณรได้รับการคุ้มครองอย่างเข้มงวด
3. **การรักษาความปลอดภัย:** ไม่ Hardcode ข้อมูล Credentials ในโค้ด และจัดเก็บค่าตัวแปรสภาพแวดล้อมอย่างปลอดภัย
