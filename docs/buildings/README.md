# เอกสารข้อมูลอาคารสถานที่และผังวิทยาเขต
## มหาวชิราลงกรณบาลีเถรวาทราชวิทยาลัย (วส. มจร)
**วัดบาลีเถรวาทสังฆาราม ตำบลรางพิกุล อำเภอกำแพงแสน จังหวัดนครปฐม**

---

## 1. ข้อมูลพื้นที่โดยรวม
* **พื้นที่ตั้งวิทยาเขต:** เนื้อที่ **๑๗๗ ไร่เศษ**
* **ที่ตั้ง:** เลขที่ ๑ หมู่ที่ ๑ ต.รางพิกุล อ.กำแพงแสน จ.นครปฐม ๗๓๑๔๐
* **พิกัดภูมิศาสตร์ (GPS):** ละติจูด 14.0325° N, ลองจิจูด 99.9856° E

---

## 2. ทำเนียบอาคาร สิ่งก่อสร้าง และพื้นที่ใช้สอยทางการ (๑๑ รายการ)

| ลำดับ | ชื่ออาคาร / สิ่งก่อสร้าง | พื้นที่ใช้สอย (ตร.ม.) | การใช้ประโยชน์และหน่วยงานที่ตั้ง |
| :---: | :--- | :---: | :--- |
| **๑** | อาคารรับรองพระอาคันตุกะ | ๑๐๐ ตร.ม. | ต้อนรับพระเถระ พระอาคันตุกะ และแขกผู้ทรงเกียรติ |
| **๒** | อาคารเรือนไม้ ๒ ชั้น (ห้องรับรอง) | ๖๐ ตร.ม. | ห้องรับรองพิเศษและสนทนาธรรม |
| **๓** | อาคารสำนักงาน ๒ ชั้น | ๑,๔๐๘ ตร.ม. | สำนักงานผู้อำนวยการ, ฝ่ายบริหารงานบุคคล, สารบรรณ, การเงินและพัสดุ |
| **๔** | อาคารห้องประชุมย่อยและปฐมพยาบาล ๑ ชั้น | ๔๐๐ ตร.ม. | ห้องประชุมสัมมนาย่อย, หน่วยปฐมพยาบาลและเวชระเบียนสุขภาวะสงฆ์ ๒๔ ชม. |
| **๕** | อาคารเรือนไทยที่พักสงฆ์ “โสภณอนันต์กิจ” | ๑๕๐ ตร.ม. | กุฏิที่พักพระเถระและอาจารย์ใหญ่ |
| **๖** | อุปัฏฐานศาลา พระราชวชิรเวที (บรรจบ ขนฺติโก) | ๔๕๐ ตร.ม. | ศาลาบำเพ็ญกุศล อุปัฏฐากพระสงฆ์ และพิธีการทางศาสนา |
| **๗** | อาคารหอสมุดและเทคโนโลยีสารสนเทศ | ๘๐๐ ตร.ม. | คลังพระไตรปิฎก ๔๕ เล่ม, ศูนย์ไอที และพุทธปัญญาประดิษฐ์ (BAI) |
| **๘** | อาคารเรียนรวม | ๑,๓๕๐ ตร.ม. | ห้องเรียนรวมบาลีศากยบุตร (A1–A6), ห้องสอบบาลีสนามหลวง และห้องบรรยายบัณฑิตศึกษา |
| **๙** | อาคารหอพัก | ๑,๓๕๐ ตร.ม. | กุฏิที่พักอาศัยและจำวัดของศากยบุตรสามเณรและพระภิกษุ ๑๔๓ รูป |
| **๑๐** | อาคารหอฉันและโรงครัวอาคารเอนกประสงค์ คศล. ๓ ชั้น | ๒,๑๐๐ ตร.ม. | โรงครัวมาตรฐาน, โต๊ะฉันภัตตาหารสงฆ์ ๑๔๓ รูป, หอประชุมเอนกประสงค์ |
| **๑๑** | อาคารห้องน้ำชาย-หญิง | ๑,๓๕๐ ตร.ม. | สุขาภิบาลและห้องสุขารวมสำหรับพระภิกษุ สามเณร และสาธุชน |
| **รวม** | **พื้นที่ใช้สอยอาคารหลัก** | **๙,๕๖๘ ตร.ม.** | **รองรับการจัดการศึกษาและการปฏิบัติศาสนกิจครบวงจร** |
