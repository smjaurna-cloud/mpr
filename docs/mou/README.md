# บันทึกข้อตกลงความร่วมมือทางวิชาการ (MOU)
## มหาวิทยาลัยมหาจุฬาลงกรณราชวิทยาลัย (มจร) & มหาวชิราลงกรณบาลีเถรวาทราชวิทยาลัย

### ๒. รายละเอียดสาระสำคัญ MOU: มจร - สจล. (พุทธปัญญาประดิษฐ์ BAI)

* **คู่สัญญา:**
  - **ฝ่ายที่ ๑ (มจร):** พระพรหมวัชรธีราจารย์, ศ.ดร. (อธิการบดี มหาวิทยาลัยมหาจุฬาลงกรณราชวิทยาลัย)
  - **ฝ่ายที่ ๒ (สจล.):** รองศาสตราจารย์ ดร.คมสัน มาลีสี (อธิการบดี สถาบันเทคโนโลยีพระจอมเกล้าเจ้าคุณทหารลาดกระบัง)
* **วัตถุประสงค์หลัก:**
  1. ร่วมกันวิจัยและพัฒนาเทคโนโลยีปัญญาประดิษฐ์สำหรับภาษาบาลีและองค์ความรู้ทางพระพุทธศาสนา ทั้งด้านการประมวลผลภาษาธรรมชาติ (NLP), การประมวลผลเสียงสวดพุทธพจน์ (Speech Recognition & TTS), และการประมวลผลภาพคัมภีร์ใบลาน (Vision OCR)
  2. พัฒนาคลังข้อมูลดิจิทัล (Digital Corpus) และองค์ความรู้ทางพระพุทธศาสนาให้เป็นฐานข้อมูลมาตรฐานที่น่าเชื่อถือสำหรับการเทรนโมเดล AI
  3. สร้างสรรค์นวัตกรรม แพลตฟอร์ม และความร่วมมือทางวิชาการสนับสนุนการเรียนการสอน การวิจัย และการเผยแผ่องค์ความรู้ทางพระพุทธศาสนา
* **กรอบความรับผิดชอบ:**
  - **มจร:** สนับสนุนคลังข้อมูลภาษาบาลี พระไตรปิฎก คัมภีร์อรรถกถา ฎีกา และคณาจารย์ผู้เชี่ยวชาญภาษาบาลีเพื่อกำกับและตรวจทานความถูกต้อง (Ground Truth Validation)
  - **สจล.:** สนับสนุนบุคลากรวิจัย วิศวกรคอมพิวเตอร์ วิทยาการข้อมูล เครื่องแม่ข่ายและพลังการประมวลผล (Compute Infrastructure/GPU) สำหรับการพัฒนาและทดสอบโมเดล AI
* **งบประมาณเชื่อมโยง:** สอดคล้องกับกรอบงบประมาณ พ.ศ. ๒๕๖๙ โครงการพัฒนาพุทธปัญญาประดิษฐ์ (BAI) วงเงิน ๓๐๐,๐๐๐ บาท
