# เอกสารและกระดานรายงานความก้าวหน้าการศึกษาของนิสิตระดับบัณฑิตศึกษา
## มหาวิทยาลัยมหาจุฬาลงกรณราชวิทยาลัย มหาวชิราลงกรณบาลีเถรวาทราชวิทยาลัย

ภาพถ่ายกระดานบอร์ดรายงานความก้าวหน้าทางการของวิทยาลัย:
1. `ตารางติดตามความก้าวหน้าวิทยานิพนธ์นิสิต.jpg` : กระดานบอร์ดสีแดงเลือดนก สำหรับนิสิตระดับปริญญาเอก (พธ.ด. พระไตรปิฎกเถรวาท รุ่นที่ ๑) จำนวน ๒๖ รูป/คน กับ ๒๑ ขั้นตอนหมุดหมาย
2. `ตารางติดตามความก้าวหน้าวิทยานิพนธ์นิสิต1.jpg` : กระดานบอร์ดสีน้ำเงิน สำหรับนิสิตระดับปริญญาโท (พธ.ม. พระไตรปิฎกเถรวาท รุ่นที่ ๑) จำนวน ๘ รูป/คน กับ ๑๕ ขั้นตอนหมุดหมาย
