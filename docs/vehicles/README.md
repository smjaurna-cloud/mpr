# เอกสารข้อมูลยานพาหนะส่วนกลางและระบบการจองรถ
## มหาวชิราลงกรณบาลีเถรวาทราชวิทยาลัย (วส. มจร)
**คลังข้อมูลยานพาหนะส่วนกลาง ๑๐ คัน และแนวปฏิบัติการขอใช้รถเพื่อศาสนกิจ**

---

### ๒. วัตถุประสงค์และระเบียบการขอใช้ยานพาหนะส่วนกลาง
1. **การรับ-ส่งพระเถระและผู้บริหาร:** เพื่อไปปฏิบัติศาสนกิจ ประชุมมหาเถรสมาคม มจร วังน้อย หรือศาสนกิจสำคัญ
2. **การนำสามเณรและพระภิกษุเข้าสอบบาลีสนามหลวง:** รถบัสใหญ่ HINO 40-1106 นครปฐม และรถตู้ จัดสรรตามตารางสอบบาลีสนามหลวงประจำปี
3. **การรับบิณฑบาตและภัตตาหารเพล:** ต้องจัดตารางเวลาให้กลับถึงวิทยาลัยก่อนเวลา ๑๑:๐๐ น. เพื่อให้ทันเวลาฉันเพล (ก่อน ๑๒:๐๐ น. ตามพระวินัย)
4. **การบริการวิชาการและการศึกษาดูงาน:** รองรับการเดินทางของนิสิตปริญญาโท-เอก สาขาวิชาพระไตรปิฎกเถรวาทและพระอภิธรรมปิฎก
5. **การสนับสนุนงานสาธารณกุศลและพิธีการสงฆ์:** รถบัสห้องน้ำพร้อมสนับสนุนงานพิธีพระราชทานเพลิงศพ งานพระราชทานกฐิน และงานอบรมพระวิปัสสนาจารย์
